# Specs

Open specs van RoxyBot-modules, elk met eisen-ID's (MOET/MAG) en een testplan.

| Spec | Module |
|---|---|
| [launcher-shell.md](launcher-shell.md) | Startscherm, schermstaten, botkanaal, bevestigingskaart, instellingen |
| [camera-tool.md](camera-tool.md) | Foto's op spraakcommando ("selfie" = front, "foto" = achter) |
| [lipsync.md](lipsync.md) | Visemen uit de audio voor Roxy's gezicht |
| [messaging.md](messaging.md) | Sms en messaging-apps, standaard na bevestiging (per kanaal uit te zetten) |
| [navigatie.md](navigatie.md) | Kaart op het hele scherm en doorsturen naar navigatie-apps |

Niet openbaar: `agent-xai`, `gemini-live`, `telephony-bridge`, `mcp-client` en `avatar` (modelroutes,
bridge, transport en Roxy's gezicht). Verwijzingen ernaar (AX-, GL-, TB-, MC-ID's) zijn hier alleen ter context.
Bronpaden en verify-commando's in de specs horen bij de gesloten app.
